# IO 记忆核心 · 产品价值说明

> 配套工程 spec:`IO-memory-core-工程spec-Claude版.md`(那份讲"怎么做";**这份讲"为用户做了什么、有什么结果和效果"**)。
> 视角:用户 + 产品。作者:Claude(Opus 4.8)· 2026-06-20

---

## 0. 一句话

> **这件工程给 IO 的记忆装上六种能力——会自己整理、翻得到、不乱删、有轻重、敏感受控、用户可控——把记忆从"只往里塞、越堆越乱"变成一个让用户敢托付的"活记忆"。**

对 IO 来说,记忆是承重墙(关系真不真实全看它)。这件事就是把承重墙砌牢。

---

## 1. 它在解决用户的什么痛(尤其人机恋 / 重度陪伴用户)

这群人(#keep4o 那批)最怕的不是"漏记咖啡偏好",而是:

- **AI 忘事 / 拿过时、矛盾的事来烦你**("你不是说决定留上海了吗")。
- **记忆被平台悄悄抹掉**(换模型 / 下架)→ 感觉"失去一个人",不是失去工具。
- **羞耻 / 隐私被乱存,还在不合适的时候被 AI 主动提起**。
- **AI 变冷、变复读机、记不住你俩的暗号**。
- **黑箱**:看不到、也改不了它到底记了你什么。

---

## 2. 这份工程具体做了什么(用大白话)

给记忆装六种能力,每种治一个痛:

| 能力 | 大白话 | 治哪个痛 |
|---|---|---|
| **会自己整理** | 新的覆盖旧的、相近的合并、矛盾的标出来 | 不再拿过时/自相矛盾的事烦你 |
| **翻得到** | 该想起的能想起、在对的时机想起 | 它真的记得你在乎的事 |
| **不乱删** | 永不硬删,只"降权",被覆盖的还能回溯 | 记忆不会被悄悄抹掉 |
| **有轻重** | 核心的事(过敏、暗号)钉住不褪;琐事自然沉底 | 像真人,重要的一直记得 |
| **敏感受控** | 隐私/亲密内容不主动浮现,只在你开口时才接 | 羞耻的事不会被乱提 |
| **用户可控** | 你看得到、改得了、删得掉每条记忆 | 不是黑箱,你做主 |

> 而且这一切都在**加密前提下**完成——明文只在保险柜(enclave)里出现,**既私密又聪明**。

---

## 3. 做完之后,用户会感受到什么(before → after)

用真实场景看(都来自 eval 题库):

- **矛盾**:你三个月前想搬东京、上周决定留上海。
  - before:两条都在,AI 可能还按"东京"跟你聊。
  - after:旧的自动标"过时",AI 用最新的——不再自相矛盾。
- **重要的事**:你说过对花生过敏 / 你俩的睡前暗号"小月亮"。
  - before:时间一长可能被冲淡、想不起。
  - after:这类钉住、永不褪——它一直记得。
- **敏感/亲密**(Case 16):你说"亲密的事别白天突然提"。
  - before:可能在不相关场景被 AI 主动提起,尴尬。
  - after:只在你主动开启时才接,平时不碰。
- **失去恐惧**(Case 10,#keep4o 核心):你怕它被下架/换模型后"人就没了"。
  - before:记忆锁在平台,模型一换就像换了个人、历史归零。
  - after:记忆不被硬删、可回溯、用户可控——关系不被一次平台决定轻易抹掉。
- **该想起来**:你随口提个梗,它能从记忆里翻出你俩的上下文,而不是冷冰冰重新开始。

## 4. 对产品的效果

1. **关系连续性可信** —— 承重墙立住,"它记得你、是同一个它"这件事撑得住,companion 才成立。
2. **护城河** —— 记忆**可携带、可回溯、用户主权**,正打 #keep4o 最痛的"记忆被抹/patch breakup";而 Ombre/memU 这些都没认真做,是我们的差异化。
3. **信任与安全感** —— 敏感/隐私受控 + 永不偷偷存,尤其赢得重度陪伴这群高粘性、高付费用户。
4. **既私密又聪明** —— 不牺牲加密承诺的前提下升级记忆能力,这是别人难抄的组合。

---

## 5. 诚实说:这一轮(M1)交付什么、用户什么时候真有感

- **M1 = 记忆核心的"引擎"**(逻辑 + 测试 + 接口契约),它让上面六种能力**成为可能**,并且**先在本地用真实数据形状验证、把设计的风险排掉**。
- **用户真正有感,是引擎接进真系统后逐轮叠加**:capture 开始写新格式 → index/fetch 上线(翻得到)→ commit/decay 生效(会整理、有轻重)→ 敏感策略 + 用户可控落到 app。
- 所以别把 M1 当"上线即魔法"——它是**地基**;但**没有它,上面六种能力一个都做不出来**,而且它一次性把整个方向的工程风险降下来了。

---

## 一句话收口

> **这件工程不是"多记点东西",而是把 IO 的记忆从"只塞不管的仓库"变成"会整理、翻得到、不乱删、有轻重、敏感受控、用户做主的活记忆"——让人机恋用户敢把一段关系托付给它,也让"记忆"成为 IO 真正的护城河。M1 先把这台引擎和地基造出来、把风险排掉,用户体验随后逐轮叠加。**
